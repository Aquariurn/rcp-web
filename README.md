# 손끝 승부

Teachable Machine 이미지 모델을 사용하는 오프라인 가위바위보 웹 게임입니다. 실행 시 인터넷 연결이 필요하지 않습니다.

## 바로 실행하기

설치 없이 아래 주소를 Chrome 또는 Edge에서 열고 카메라 권한을 허용하세요.

**https://aquariurn.github.io/rcp-web/**

> 배포된 웹사이트를 사용할 때는 모델과 라이브러리를 처음 내려받기 위한 인터넷 연결이 필요합니다. Python이나 별도 프로그램은 설치하지 않아도 됩니다.

## 내 모델 사용

1. Teachable Machine 모델 화면에서 `Export Model`을 누릅니다.
2. `Tensorflow.js` 탭에서 `Download my model`을 선택해 다운로드합니다.
3. 압축을 풀고 게임 화면 오른쪽 위의 설정 버튼을 엽니다.
4. `model.json`, `metadata.json`, `weights.bin`을 각각 선택하고 `선택한 모델 적용`을 누릅니다. 가중치 파일이 여러 개라면 모두 선택하세요.

```text
내려받은 모델/
├── model.json
├── metadata.json
└── weights.bin (또는 여러 개의 .bin 파일)
```

모델 클래스 이름은 `가위`, `바위`, `보` 또는 `scissors`, `rock`, `paper`여야 합니다.
선택한 파일은 서버로 전송되지 않고 현재 브라우저 탭의 메모리에서만 사용됩니다. 페이지를 새로고침하면 프로젝트에 포함된 기본 모델로 돌아갑니다.

설정 창의 `기본 모델 사용` 버튼을 누르면 새로고침하지 않고도 기본 모델로 돌아갈 수 있습니다.

## 기본 모델 교체

웹사이트가 처음 열릴 때 사용하는 모델을 바꾸려면 Teachable Machine에서 내려받은 다음 파일을 프로젝트의 `model/` 폴더에 넣으세요.

```text
model/
├── model.json
├── metadata.json
└── weights.bin
```

## 실행

카메라는 보안 정책상 `file://`에서 제한될 수 있으므로 로컬 서버로 실행하세요.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. AI 라이브러리와 모델을 모두 프로젝트 내부에서 읽으므로 이후 인터넷 연결을 끊어도 사용할 수 있습니다.

다른 노트북으로 옮길 때는 `vendor/`와 `model/` 폴더를 포함한 프로젝트 전체를 복사하세요.

## 동작 검증

Node.js 18 이상이 설치된 환경에서 별도 패키지 설치 없이 실행할 수 있습니다.

```bash
node --test tests/app.test.cjs
```

기본 모델과 사용자 파일의 로딩·검증·해제, 카메라 실패·페이지 이탈, 추론 오류 복구, 승패·점수 초기화를 검증합니다. 실제 모델의 CPU 추론과 가중치 해제도 확인하며, 카메라 권한과 화면 표시는 브라우저에서 별도로 확인해야 합니다.
